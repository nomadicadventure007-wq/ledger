👑管理者能做什麼

建立旅程的人就是管理者（設定頁會顯示「👑 管理員」）。一趟旅程只有一位管理者，但可以轉讓。

項目管理者成員
記帳、換匯、看全部✅✅
修改／刪除自己記的✅✅
修改／刪除別人記的✅❌
成員、公款、分類、匯率、預算✅❌（看不到）
搬到雲端、邀請碼、撤銷、刪除雲端旅程✅❌（看不到）
按「已結清」、處理「待管理員確認」的帳（結清後補記、金額差異較大）✅❌
付款人可以選誰✅ 任何人（代記）只能選自己或公款
調整「待確認」的容許範圍✅❌（看不到）

匯出 CSV、備份與還原、匯入 CSV✅❌（看不到）

成員的手機看得到什麼

成員只看得到：記帳、錢包、歷史、我的，以及設定裡的「立即同步」「離開雲端」「使用說明」。不能用的功能，在他們的畫面上完全不會出現。成員能複製轉帳文字貼到 LINE，但不能匯出 CSV 或備份，需要帳目檔時，請由你匯出再分享給大家。

💡 這些權限由雲端伺服器把關，不是只靠 App 畫面。成員就算改了自己手機上的程式，伺服器也不會接受。

🧭第一次設定（照順序做）

  1. 部署後端與 App：先照「部署指南」完成 Cloudflare 與 GitHub Pages，並跑完驗收（後端的 node --test test/*.test.mjs 與 node smoke.mjs 網址 都沒有失敗）。
  2. 建立旅程：先「加入主畫面」，從主畫面圖示開啟 App。第一個畫面只有「輸入邀請碼」（這是給旅伴看的），請連點上方的封面圖五下，就會出現「＋ 建立旅程」。輸入名字；取消勾選「沿用…」可自訂成員（逗號分隔，第一位是你）和幣別與匯率（每行一個，例：JPY 0.23）。之後想再開新旅程，到設定 →「＋ 新旅程」。
  3. 調整設定：到「成員／公款／分類／匯率／預算」補齊。
  4. 搬到雲端：設定 →「☁️ 把這趟旅程搬到雲端」→ 輸入你的建立金鑰（SETUP_KEY）→ 上傳。
  5. 存好恢復碼與旅程編號：上傳完成會顯示只此一次的恢復碼，請截圖並存進密碼管理員。旅程編號之後在雲端區也看得到。
  6. 邀請旅伴：雲端區每位成員旁按「邀請碼」→ 分享到 LINE。對方輸入後，狀態會變成「已加入」。
⚠️ 恢復碼只顯示一次。弄丟的話仍能救援（見「救援」），但請務必先存好。

🗂️日常管理

設定頁的各區

區塊可以做什麼
成員、公款新增、改名、換表情、換頭像（上傳照片，或填 GitHub 圖片檔名如 img/smile.png）、刪除（有紀錄用到的不能刪）、設為管理員
分類新增、改名、換表情與顏色、換圖片；刪除後舊紀錄會歸到最後一個分類
匯率直接修改數字；「＋ 幣別」新增。只影響之後的紀錄，已記的不會變
預算填總預算（台幣）與旅程天數；「我的」頁會顯示進度與每天可花金額
待確認的容許範圍預設 ±5%（可填 0～50）。成員填的台幣金額和「金額 × 匯率」差距超過它、或匯率和參考匯率差超過它的 3 倍，就會標「待管理員確認」（見「待確認的帳」）

幫別人記帳

  • 代誰操作：設定頁最上面的下拉選單（只有你看得到）。選了某位成員後記的帳，記錄者就是那位成員，適合幫沒帶手機的旅伴記；這時付款人可以選任何人（成員自己只能選自己或公款）。記完記得切回自己。
  • 收進來：成員網路不好時，把「📤 傳給對方」產生的同步碼用 LINE 傳給你，你在設定按「📥 收進來」貼上、預覽、合併，帳會用原本記錄者的名字進來，並自動同步到雲端。
💡 你代記或改過的紀錄，那位成員自己就不能再修改或刪除了。要改請由你處理。

圖片放 GitHub

  1. 準備正方形、約 200～256px、小於 100KB 的 PNG（透明背景最好），檔名用英文小寫，例如 smile.png。
  2. 到 GitHub repo 的 img 資料夾 → Add file → Upload files → Commit。
  3. 在 App 的成員或分類編輯面板，「圖片檔名」填 img/smile.png。
💡 放在 GitHub 的圖片不受雲端 300KB 設定上限影響；在 App 裡「上傳照片」的方式才受影響，建議全部圖片合計不要超過 10 張左右。

⏳待確認的帳與容許範圍

為了避免打錯字或亂填，成員記的帳如果出現下面的情況，會先標「⏳ 待管理員確認」，不會計入結算與錢包，等你處理：

情況怎麼判斷
金額差異較大換匯的匯率、或成員鎖定的台幣金額，和參考值（你設定的匯率）差距超過容許範圍。最常見的是換匯時多打或少打一個 0
結清後補記成員在結清之後，補記「結清日以前」的帳

在哪裡處理

「歷史」頁最上面會多一區「⏳ 待你確認（N）」，點進去有三個選項：

  • 同意，計入結算：這筆就算數，成員之後不能再改。
  • ✏️ 我來改一下（金額差異較大時才有）：由你改成正確的金額；你改過的紀錄不會再被標待確認。
  • 不要，刪掉：刪除。

容許範圍怎麼調

設定頁的「待確認的容許範圍」填 0～50 的數字，預設 5（%）：成員填的台幣金額和「金額 × 匯率」差距超過這個比例，就要確認。匯率的門檻是它的 3 倍（預設 15%），因為你中途可能調整過匯率。填 0 代表只要有一點點不一樣就要確認；數字越大越寬鬆。

💡 你自己記的帳不會被標待確認。成員也可以自己把金額改回合理的值，標記就會自動消失，不一定要等你。這些判斷由雲端伺服器執行，成員改程式也繞不過去。

🧾結算與結清

  1. 先確認資料齊全：「我的」頁會顯示資料指紋，並在有成員還沒加入時提醒。請成員都按過「立即同步」，並先處理完歷史頁最上面的「待你確認」（它們不會計入結算，結算頁會寫「另有 N 筆等管理員確認」）。
  2. 看「誰該付給誰」：可按 📋 複製，貼到 LINE 通知大家。
  3. 大家轉帳完成後，按那一筆的「已結清」。系統會記下結清日，並產生一筆「結清」紀錄。

結清之後有人補記舊帳

成員在結清後，補記「結清日以前」的帳，會標「⏳ 待管理員確認」，不會計入結算（金額差異較大的帳也在同一個地方處理，見「待確認的帳」）。你點進去：

  • 「同意，計入結算」：計入，之後需要的話再結清一次。
  • 「不要，刪掉」：刪除。
💡 刪掉某筆「結清」紀錄，帳就會回到未結清的狀態。成員無法匯出帳目，需要時由你匯出 CSV 再分享。

👥成員管理

情境做法
新增旅伴設定 → 成員 →「＋ 新增」→ 再到雲端區按他旁邊的「邀請碼」
旅伴換手機在雲端區重新按他的「邀請碼」，新手機加入後，舊手機會自動失效
旅伴手機遺失按他旁邊的紅色「撤銷」，對方手機立刻無法同步；之後可再發邀請碼
轉讓管理員設定 → 成員 → 點那位成員 →「設為管理員 👑」。系統會換一組新恢復碼並顯示，請交給新管理員保管，你自己則變成一般成員

🆘救援：手機或恢復碼弄丟了

有恢復碼

  1. 新手機打開 App，在第一個畫面連點上方的封面圖五下。
  2. 在「管理者」區輸入旅程編號和恢復碼，按「用恢復碼找回管理員」。
  3. 找回後舊手機的憑證立刻失效，並顯示一組新的恢復碼，請重新存好。

恢復碼也弄丟了

資料都還在你的 Cloudflare 資料庫，你可以自己重設。在後端（worker）資料夾的終端機：

  1. 查旅程編號：wrangler d1 execute ledger-db --remote --command "SELECT id,name,admin_id FROM trips"
  2. 產生新恢復碼：node reset-recovery.mjs 旅程編號
  3. 執行它印出來的那一行 wrangler 指令。
  4. 回到 App，連點封面圖五下，輸入旅程編號與新恢復碼，按「用恢復碼找回管理員」。
⚠️ 能登入你 Cloudflare 帳號的人，就能接管所有旅程。請替帳號開啟雙重驗證，並保存備援碼。

🔧維護與更新

要做的事做法
更新 App把新版檔案覆蓋到 GitHub 資料夾並上傳（改過任何檔案後，先在專案資料夾執行 node tools/build-sw.mjs，離線快取清單與版本號才會更新）。使用者打開 App 會看到「有新版本」，按「更新」即可
更新後端覆蓋 worker 資料夾，在裡面執行 wrangler deploy，再跑一次驗收 node smoke.mjs 網址
手動備份整個資料庫wrangler d1 export ledger-db --remote --output=backup.sql
每日自動備份（選用）在後端資料夾執行 wrangler r2 bucket create ledger-backups，再把 wrangler.toml 裡 [[r2_buckets]]、[triggers] 那幾行的註解拿掉，wrangler deploy。之後每天自動備份一份，只留最近 30 份
從自動備份還原wrangler r2 object get ledger-backups/ledger-日期.json.gz --file backup.json.gz --remote（也可以直接到 Cloudflare 網站的 R2 頁面把那個檔案下載下來；若你的 wrangler 不認得 --remote，把它拿掉）；node restore-backup.mjs backup.json.gz --replace-all > restore.sql；wrangler d1 execute ledger-db --remote --file=restore.sql（不加 --replace-all 只會補回備份裡有的資料）
離開雲端雲端區「離開雲端」：這支手機停止同步，資料保留在本機，其他人不受影響
刪除雲端旅程雲端區「刪除雲端旅程」，輸入旅程名稱確認。永久刪除伺服器上的整趟旅程，各人手機裡的資料不會被刪

🏁旅程結束時

  1. 請大家都按「立即同步」，確認「我的」頁沒有未加入的警告。
  2. 逐一按「已結清」，處理「待管理員確認」的補記帳。
  3. 設定 →「⬇︎ 匯出帳目 CSV」存下整趟帳目；再按「💾 備份」。
  4. （選擇性）刪除雲端旅程。

如果有填預算天數，到了預定最後一天，App 會自動跳出「🎉 旅程結束了」，讓你一鍵匯出與備份。

❓問題排查

App 顯示「連不上伺服器」
用瀏覽器打開 https://ledger.nomadic1103.workers.dev/api/health，沒有出現 ok 就是後端問題，到後端資料夾重新 wrangler deploy。有出現 ok，檢查手機網路。
成員說「憑證失效」
他的憑證被撤銷，或他換了手機。重新發一組邀請碼給他。
成員改了東西，畫面跳出「⚠️ …」
這是伺服器的權限保護。對照下表。
設定頁出現「有 N 筆資料格式壞掉」
那些紀錄的格式有問題（欄位缺漏或型別錯誤），App 已經先把它們移到旁邊保管：不計入結算，也沒有被刪除。點「查看」看原因，按「複製內容」可以把原始資料貼給開發者。新版伺服器不會再收下這種資料，所以多半是舊版留下的。
成員說畫面顯示「這一頁出了點問題」
資料沒有遺失。請他按「回到記帳頁」或「重新整理」；若一直發生，按「複製錯誤訊息」傳給你。
邀請碼說已使用或過期
邀請碼只能用一次、7 天有效。重發一組。
上傳雲端時說「沒有建立旅程的權限」
建立金鑰（SETUP_KEY）輸入錯誤，到密碼管理員複製後重貼。需要換金鑰：wrangler secret put SETUP_KEY。
